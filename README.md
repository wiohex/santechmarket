# СантехМаркет — с чего начать

Весь проект находится в этой папке. Код сайта — в `app/`, вспомогательные команды — в `scripts/`. База и фотографии хранятся отдельно от кода.

## Каждый раз: открыть сайт

1. Дважды нажмите **START.cmd** в этой папке.
2. Дождитесь открытия браузера. Адрес сайта: **http://127.0.0.1:8000**.
3. Окно запуска оставьте открытым — в нём работает сервер.
4. Чтобы остановить запущенный этим файлом сервер, нажмите **Ctrl+C** в его окне.

Если сайт уже запущен, START.cmd просто откроет его, не создавая второй сервер. В этом случае останавливать его нужно в исходном окне запуска. **OPEN.cmd** только открывает браузер: сам сервер он не запускает.

Сайт работает локально на этом компьютере. Для доступа другим людям потребуется отдельно настроенное размещение на сервере.

## Войти владельцем

1. Откройте **http://127.0.0.1:8000/login**.
2. Используйте email владельца или его логин и действующий пароль.
3. Для этой настроенной копии исходные данные находятся в локальном `.env`: `ADMIN_EMAIL`, `ADMIN_LOGIN`, `ADMIN_PASSWORD`. Если пароль уже менялся, используйте актуальный.
4. Панель владельца: **http://127.0.0.1:8000/admin**.

`.env` открывается обычным Блокнотом. Не пересылайте его вместе с исходниками: в нём пароли и ключи. Изменение `ADMIN_PASSWORD` в `.env` не меняет пароль уже созданной учётной записи.

## Загрузить свою базу товаров из Excel или CSV

Полная пошаговая инструкция и описание столбцов: **[docs/import-products.md](docs/import-products.md)**.

Коротко:

1. Сделайте резервную копию командой ниже.
2. Подготовьте `.xlsx` или `.csv` по образцу `app/static/price-example.csv`.
3. Войдите владельцем и откройте **http://127.0.0.1:8000/admin/import**.
4. Выберите файл → **Проверить файл** → проверьте таблицу → **Подтвердить импорт**.
5. Откройте каталог и проверьте товары, цены и наличие.

Базы 1С, Access, произвольные `.sql` и чужие `.db` напрямую не загружаются. Из них нужно выгрузить таблицу товаров в Excel/CSV и привести её к нужным столбцам. Готовая база именно этого сайта переносится другим способом — см. **[docs/database.md](docs/database.md)**.

## Сохранить копию базы и фотографий

Откройте терминал PowerShell в этой папке и выполните:

```powershell
.\.venv\Scripts\python.exe -m scripts.backup
```

Появится новая папка `backups/дата_время/` с `store.db` и копией `uploads/`. База копируется через SQLite backup API, включая сохранённые изменения из WAL. Для согласованной копии фотографий на время резервирования не редактируйте товары и не загружайте фото. `.env` в копию не входит: при переносе сохраните его отдельно в закрытом месте.

## Если установка на новом компьютере

Нужен установленный Python 3.11 или новее. Команды выполняются в PowerShell из папки проекта, по одной; при ошибке сначала исправьте её.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe -m scripts.init_env
notepad .env
```

В `.env` заполните `ADMIN_EMAIL` своим email. Можно задать `ADMIN_LOGIN`. Случайный `SECRET_KEY`, созданный командой, сохраните. `DATABASE_URL=sqlite:///./store.db` подходит для обычной локальной работы.

Затем:

```powershell
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m scripts.create_admin
```

Если `ADMIN_PASSWORD` пустой, команда попросит ввести пароль дважды. При вводе символы могут не отображаться — это нормально. После этого запускайте **START.cmd**.

Для необязательного демо-каталога:

```powershell
.\.venv\Scripts\python.exe -m scripts.seed
```

Если переносите готовую базу этого сайта, сначала прочитайте [инструкцию переноса](docs/database.md). Повторно создавать владельца в перенесённой базе не нужно.

## Где что лежит

| Путь | Что находится внутри |
|---|---|
| `app/` | Весь код и оформление сайта |
| `scripts/` | Запуск, создание настроек и владельца, демо-товары, резервная копия |
| `migrations/` | Создание и обновление структуры базы |
| `tests/` | Автоматические проверки |
| `docs/` | Инструкции и технические сведения |
| `store.db` | Рабочая база: товары, пользователи, заявки |
| `uploads/` | Загруженные фотографии |
| `.env` | Локальные настройки и секреты |
| `backups/` | Резервные копии, появляются после команды backup |
| `screenshots/` | Превью внешнего вида; сайт их не использует |
| `.runtime/` | Старые локальные логи, PID и проверочные снимки |
| `.venv/` | Установленные Python-библиотеки; на новом ПК создаётся заново |

`store.db-wal` и `store.db-shm` — служебные части работающей SQLite-базы. Не удаляйте их и не переносите по отдельности во время работы сайта.

## Телефон и оформление

Настоящий телефон задаётся в `STORE_PHONE` файла `.env`. После изменения перезапустите сервер. Пока номер не заполнен, шапка показывает демо-номер и не совершает звонков.

Главная использует единый класс `.glass`; на мобильных экранах размытие отключено. Формы, кабинет и админка работают на плотном белом фоне. Фото на главной теперь статично.

## Если что-то не открывается

- **Браузер пишет, что сайт недоступен:** запустите START.cmd и посмотрите ошибку в его окне.
- **Нет `.venv` или `.env`:** выполните раздел установки выше. Существующий `.env` не заменяйте примером.
- **Порт 8000 занят чужой программой:** освободите порт либо запустите сайт вручную на другом порту:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

Тогда адрес — `http://127.0.0.1:8001`; START.cmd и OPEN.cmd рассчитаны на 8000.

- **После правки оформления вид старый:** обновите страницу сочетанием Ctrl+F5.
- **Ошибка импорта:** проверьте [формат файла](docs/import-products.md). До подтверждения импорт не меняет каталог.
- **Изменили `.env` или Python-код:** перезапустите сервер. Обычный START.cmd не включает автоматическую перезагрузку.
