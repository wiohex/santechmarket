# Карта проекта и правила работы с кодом

## Где искать нужное изменение

```text
app/
  main.py                сборка FastAPI, middleware, подключение маршрутов
  config.py              настройки из .env
  security.py            сессии, пароли, CSRF, ограничение входа
  web.py                 общие функции отрисовки страниц
  routers/
    public.py            главная, каталог, карточка товара
    auth.py              вход, регистрация, выход
    requests.py          список покупок и отправка заявки
    account.py           кабинет магазина
    admin.py             действия владельца и импорт прайса
  services/
    imports.py           чтение и применение CSV/XLSX
    requests.py          создание заявок
    uploads.py           проверка и сохранение фотографий
    notifications.py     уведомления Telegram
  models/                таблицы SQLAlchemy
  schemas/               проверка введённых данных
  db/                    подключение к базе
  templates/             HTML/Jinja2
    base.html            общая оболочка, шапка, подвал
    home.html            главная
    admin/               страницы владельца
    account/             страницы магазина
    _*.html              общие повторяемые фрагменты
  static/
    style.css            только подключение CSS в нужном порядке
    css/
      base.css           общие элементы, формы, таблицы, базовый адаптив
      storefront.css     оформление витрины и его адаптив
      glass.css          общий материал, контраст, белые рабочие страницы и fallback
      glass-header.css   компоновка шапки и контактов
      home.css           стекло и оформление только главной
    app.js               общие действия (подтверждения форм и возврат назад)
    images/              фоновые изображения
    *.svg                иллюстрации и иконки
    price-example.csv    образец импорта для скачивания
scripts/                 служебные команды, не код страниц
migrations/              версии структуры базы
tests/                  проверки поведения
docs/                   инструкции
```

CSS разделён по назначению с сохранением прежнего порядка правил. `base.css` содержит базовое оформление, а `storefront.css` накладывает оформление витрины. Это существующие слои, а не два альтернативных варианта: их не нужно подключать отдельно или менять местами. Правки главной вносятся в home.css и ограничиваются классом `.home-page`.

## Чтобы код не превращался в один большой файл

- Маршрут принимает HTTP-запрос и возвращает ответ. Чтение файлов и работу с заявками выносите в `services/`.
- Структуру таблиц меняйте через `models/` и новую миграцию. Не исправляйте рабочую базу вручную ради нового поля.
- HTML правьте в `templates/`; повторяемые куски — в общих `_*.html`.
- Дизайн правьте в соответствующем CSS-файле, не дописывайте всё подряд в style.css. Проверяйте десктоп и мобильную ширину.
- Действия в браузере — в app.js. Если появится отдельная крупная функция, выделите ей свой JS-файл.
- Пароли и токены храните только в `.env`, значения по умолчанию — в `.env.example` без секретов.
- Рабочую базу, uploads и backups не храните внутри app и не добавляйте в Git.

## Проверки после изменения логики

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pip check
```

Тесты используют временные базы. Для проверки моделей после миграций: `.\.venv\Scripts\python.exe -m alembic check`.

Внешний вид дополнительно проверяйте в браузере: автоматические серверные тесты не проверяют CSS. Полное описание возможностей и ограничений — в [technical-guide.md](technical-guide.md). Старые планы в `docs/superpowers/` и отчёт `verification.md` — история разработки, а не инструкция ежедневного запуска.

## Стеклянные поверхности

Все парящие поверхности используют `.glass` из `glass.css`: белый фон 0,72, blur 14px и saturate 140%. Вложенные карточки не размывают фон повторно. При ширине до 700px и `prefers-reduced-transparency: reduce` поверхности непрозрачные. Без поддержки backdrop-filter исходный фон белый.

Заголовки входят в общую поверхность секции; отдельных белых плашек под ними нет. Фон главной статичный, без обработчика прокрутки. Рабочие страницы (вход, кабинет, заявки, админка) используют `.work-page` и плотный белый фон без фотографии. Основной текст 16px, подписи от 13px.

Телефон в шапке берётся из `STORE_PHONE`. Пока он не заполнен, показан явно подписанный демо-номер, а кнопка звонка отключена. После задания настоящего номера и перезапуска появляется ссылка `tel:`.
