# Импорт товаров: Excel и CSV

## 1. Подготовить файл

Возьмите образец `app/static/price-example.csv` или скачайте его на странице http://127.0.0.1:8000/admin/import. Его можно открыть в Excel, заменить строки своими товарами и сохранить как `.xlsx`.

| Заголовок | Обязательно | Что писать | Пример |
|---|---|---|---|
| `sku` | Да | Уникальный артикул товара | MIX-001 |
| `name` | Да | Название товара | Смеситель для кухни |
| `category` | Да | Название категории | Смесители |
| `price` | Да | Цена в рублях, без обозначения валюты | 2490.00 |
| `in_stock` | Нет | Наличие: 1/0, да/нет, true/false, yes/no | 1 |
| `description` | Нет | Описание обычным текстом | Высокий излив |

Заголовки пишутся латиницей, как в таблице. Первая строка — заголовки, остальные — товары. Не используйте объединённые ячейки. У `.xlsx` читается только первый лист; формулы предварительно замените значениями. `.xls` сохраните как `.xlsx`.

Цена неотрицательная, максимум 100 млн рублей, до двух знаков после запятой. Можно использовать десятичную запятую; для CSV тогда выбирайте разделитель `;`. Файл — не более 2 МБ и 1000 товаров. В XLSX лимит физических строк — 1001 вместе с заголовком, включая пустые строки. CSV поддерживает UTF-8 и Windows-1251.

## 2. Загрузить

1. Сохраните резервную копию: из корня проекта выполните `.\.venv\Scripts\python.exe -m scripts.backup`.
2. Откройте http://127.0.0.1:8000/login и войдите владельцем.
3. Перейдите на http://127.0.0.1:8000/admin/import.
4. Выберите файл и нажмите **Проверить файл**.
5. Проверьте число строк и первые 20 товаров в таблице. На этом этапе база ещё не меняется.
6. Нажмите **Подтвердить импорт** и подтвердите действие в браузере.
7. Проверьте товары в админке и в каталоге.

## 3. Как обновляются товары

- Совпадает артикул — обновляется существующий товар; новый артикул — создаётся новый товар.
- Новые категории создаются автоматически.
- Товары, которых нет в файле, остаются в базе.
- Фото существующих товаров сохраняются. Фотографии добавляются отдельно в редакторе товара.
- Все импортированные товары становятся активными, включая ранее скрытые.
- Если столбца `in_stock` нет, импорт поставит «в наличии».
- Если столбца `description` нет, описание импортируемого товара станет пустым.
- Повторяющиеся артикулы внутри одного файла и неверные строки отклоняются; при ошибке весь импорт не применяется.

## 4. Если база из другой программы

Из 1С или другой программы выгрузите список товаров в Excel/CSV. Переименуйте столбцы и перенесите значения по таблице выше. Автоматического подключения к 1С и загрузки произвольных SQL-баз нет. Этот импорт загружает товары, а не пользователей и историю заявок.

Для переноса базы **этого сайта** вместе с аккаунтами и заявками используйте [database.md](database.md).
