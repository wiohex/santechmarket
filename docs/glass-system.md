# Стеклянная система, 30.10.2026

Материал определён один раз в `app/static/css/glass.css`: `.glass`, белый фон 0,72, blur 14px, насыщенность 140%, светлая рамка и мягкая тень. Шапка, секции витрины, карточки, фильтры, баннер компаний и контакты используют этот класс. Заголовки входят в секции, без отдельных плашек.

Вложенная `.glass` не создаёт повторный blur. При ширине до 700px и при запросе уменьшенной прозрачности фон становится белым без размытия. Белый fallback задан до `@supports`. Рабочие страницы имеют `.work-page`, плотный белый фон и не показывают фотографию.

Фон главной статичен: обработчики scroll/resize, requestAnimationFrame и will-change для прозрачности удалены. Исходное фото сохранено без дополнительного затемнения.

## Контраст

Текст: `#172b45`, второстепенный текст: `#334155`, ссылки: `#12359c`. Для белой поверхности с alpha 0,72 самая тёмная возможная подложка получается при чёрном изображении под ней: RGB(183.6, 183.6, 183.6). Размытие не может дать более тёмный цвет, чем чёрный.

Контраст рассчитывается по относительной яркости sRGB: `(Lсветлый + 0.05) / (Lтёмный + 0.05)`. Для второстепенного текста в этом худшем случае результат 5,197:1, для ссылок — более 5,2:1. Фото не пришлось изменять или повышать непрозрачность стекла.

В браузере проверены вычисленные цвета 102 текстовых элементов главной с композицией всех родительских заливок над чёрной подложкой. Минимум 5,2:1; значений ниже 4,5:1 и размеров шрифта ниже 13px не обнаружено. Подписи внутри картинок товаров вынесены в HTML, чтобы их размер не уменьшался вместе с изображением. Основные абзацы — 16px.

## Проверка интерфейса

- Ширины 320, 390, 700, 701 и 1320px: горизонтального переполнения страницы нет.
- До 700px включительно: активных backdrop-filter нет.
- На 1320px в верхнем экране — 3 размываемые поверхности; вложенные карточки не создают дополнительные слои.
- После прокрутки opacity фона остаётся 1.
- Страница входа: фото отсутствует, форма белая, backdrop-filter выключен, подвал у нижнего края.
- Каталог: фильтры используют общий материал, карточки внутри общей поверхности не размывают фон повторно.
- Физический слабый Android не тестировался; проверена мобильная компоновка в браузере.

Телефон читается из STORE_PHONE. Пустое значение показывает подписанный демо-номер с отключённой кнопкой; настоящий номер формирует ссылку tel: с нормализованными цифрами. Серверные тесты покрывают оба случая.
