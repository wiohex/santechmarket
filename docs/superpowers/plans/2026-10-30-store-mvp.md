# Store MVP Implementation Plan

Goal: рабочий локальный MVP магазина сантехники с каталогом, заявками, B2B и админкой.
Architecture: FastAPI, Jinja2, SQLAlchemy, серверные сессии. SQLite по умолчанию; DATABASE_URL для PostgreSQL. Все изменения через POST и CSRF.
Spec: подтверждённая пользователем структура и схема в чате от 2026-10-30.

## Constraints
Без оплаты, доставки, 1С. Русский адаптивный интерфейс, Windows PowerShell. Секреты только в .env. Сначала БД → каталог → заявки → админка → B2B → Telegram → тесты → README.

## Review focus
- Подмена цены/количества и повторная отправка заявки.
- Чужие заявки, обход роли, просроченные сессии и CSRF.
- Неверный CSV/XLSX, частичный импорт, формулы и дубликаты артикула.
- Поддельные изображения и большие загрузки.
- Сбой Telegram после сохранения заявки.
